# Application identity

`substance_painter.png` is the Adobe Substance 3D Painter application icon,
extracted at 32×32 from the installed Adobe Substance 3D Painter executable.
It identifies the Open Painter Project action, not MBToolkit itself.
Adobe and Substance 3D Painter names and artwork belong to Adobe; this asset is
not original MBToolkit artwork and is not covered by a claim of toolkit authorship.
